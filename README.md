# Login - Interfaces Móviles

Práctica de diseño de interfaces móviles: pantalla de inicio de sesión (solo interfaz) desarrollada en Android Studio.

## Descripción

Pantalla de login con campos de correo y contraseña, opción para mostrar u ocultar la contraseña, recuperación de contraseña, botón de Google y enlace de registro.

## Tecnologías

- Android Studio
- XML con Material Design 3
- Java

## Fases de la práctica

1. Investigación y arquitectura
2. Bocetos
3. Wireframe
4. Mockup
5. Prototipo en Android Studio

## Cómo ejecutarlo

1. Clona el repositorio:
   `git clone https://github.com/BrianGoznalez/LOGIN_INTERFACES_MOVILES.git`
2. Ábrelo con Android Studio.
3. Espera a que termine la sincronización de Gradle.
4. Ejecuta la app en un emulador o dispositivo.
